# Ordenação de Algoritmos em Python

Atividade desenvolvida para a disciplina de Algoritmos da graduação em Engenharia de Software.

O projeto tem como objetivo implementar diferentes algoritmos de ordenação utilizando Python e comparar o comportamento de cada um deles utilizando listas com números aleatórios.

Foram implementados algoritmos simples e avançados para analisar diferenças de desempenho, velocidade e estratégia de ordenação.

Algoritmos utilizados:

- Selection Sort
- Bubble Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort
- Counting Sort
- Radix Sort
- Bucket Sort

O projeto também utiliza geração de listas aleatórias para realização dos testes de ordenação.
